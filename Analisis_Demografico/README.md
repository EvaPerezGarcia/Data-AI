# Análisis de IDH, PIB y tasa de natalidad

Este proyecto, realizado para la asignatura **Técnicas de Programación**, analiza la relación entre tres indicadores socioeconómicos: el Índice de Desarrollo Humano (IDH), el Producto Interior Bruto (PIB) y la tasa de natalidad.

A partir de datos obtenidos de fuentes públicas, se desarrolla un proceso de tratamiento, análisis y visualización utilizando **Python**, con el objetivo de explorar los indicadores e interpretar la información socioeconómica disponible.

## <code>02 /</code> PROCESO DE ANÁLISIS

El análisis se desarrolla mediante **Python**, utilizando Jupyter Notebook como entorno de trabajo.

El proyecto aborda los siguientes aspectos:

- **Obtención de datos:** recopilación de información sobre IDH, PIB y tasa de natalidad a partir de fuentes públicas disponibles en internet.
- **Tratamiento de datos:** preparación de los conjuntos de datos para facilitar su análisis.
- **Análisis exploratorio:** estudio de los indicadores y de su comportamiento.
- **Comparación de variables:** exploración de posibles relaciones entre el desarrollo humano, la riqueza económica y la natalidad.

---
