# Diseño de Base de Datos Relacional para un Marketplace | MySQL

Este proyecto desarrolla el diseño de una **base de datos relacional para un marketplace de compraventa de productos de segunda mano**, utilizando MySQL.

El trabajo aborda la definición de la estructura de la base de datos, el establecimiento de relaciones entre tablas y la elaboración de consultas SQL para gestionar y recuperar información.

## <code>02 /</code> DISEÑO DE LA BASE DE DATOS

Se diseñó un modelo relacional para representar las principales entidades y operaciones de un marketplace de compraventa de productos usados.

El diseño contempla:

- **Estructura de tablas:** definición de las entidades y sus atributos.
- **Claves primarias:** identificación única de los registros.
- **Claves foráneas:** establecimiento de relaciones entre las distintas tablas.
- **Integridad referencial:** definición de restricciones para mantener la coherencia de los datos.
- **Relaciones entre entidades:** organización de la información para representar las operaciones propias de la plataforma.

---

## <code>03 /</code> INSERCIÓN DE DATOS Y CONSULTAS SQL

Se desarrolló un script SQL para trabajar con el modelo de datos diseñado.

Incluye:

- **Inserción de datos:** incorporación de registros de ejemplo en las distintas tablas.
- **Consultas SQL:** recuperación y combinación de información mediante consultas.
- **Interacción con el modelo:** comprobación del funcionamiento de las relaciones y de la estructura de la base de datos.

## <code>04 /</code> HERRAMIENTAS Y TECNOLOGÍAS

---

## <code>05 /</code> CONSIDERACIONES SOBRE EL PROYECTO

El proyecto tiene un carácter académico y práctico. El modelo de datos representa un escenario ficticio de compraventa de productos de segunda mano y permite aplicar conceptos de diseño relacional, organización de información y gestión de bases de datos.

Los registros incluidos en el script SQL son datos de ejemplo y no corresponden a operaciones reales de un marketplace.
